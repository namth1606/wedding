# Hoài Nam & Thiên Trang

Wedding invitation: https://namth1606.github.io/wedding/

The site is a standalone `index.html` with embedded photos, fonts and music. It includes an animated envelope, English/Vietnamese language switching, and RSVP and guest-book forms connected to Google Sheets through Apps Script.

To publish changes, update `index.html` and push to `main`. GitHub Pages serves the site from this repository.
